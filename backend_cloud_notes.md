# Backend Cloud Notes

## What is PostgreSQL?

A relational database used by backend applications.

## What is AWS RDS?

Managed cloud database service by AWS.

## Local DB vs Cloud DB

Local DB runs on developer machine.
Cloud DB runs remotely on cloud infrastructure.

## Django Database Connection

Django connects using:

- ENGINE
- NAME
- USER
- PASSWORD
- HOST
- PORT

## Backend Flow

Frontend → Backend → Database
